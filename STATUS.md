# STATUS — SkyGuard (updated 2026-10-10)

## What works (verified on the laptop, simulation + laptop-stand-in profiles)
* Full pipeline end to end in **sim**: `python -m skyguard run` → dashboard at http://localhost:8000 → **Run demo** (approach → audio ≈6 s → Wi-Fi ≈17–20 s → Remote ID → vision ≈31 s → DRONE alert → leaves ≈60 s). Test buttons per detector.
* **`laptop` profile**: this laptop's real webcam (YOLOv8n ONNX), mic and Wi-Fi radio drive the real detectors live (mic reads near-silence — probably OS-muted; webcam and `netsh` scan fine).
* **`pi` profile boots on the laptop and degrades gracefully** (missing LCD/BLE/ALSA/Nest drivers are logged and skipped).
* Detectors: acoustic (dataset-tuned), vision (fine-tuned YOLOv8n), Wi-Fi SSID/OUI + RSSI trend, BLE Remote ID decode, 2-node Bayesian localizer, persistence-gated fusion, SQLite event log, snapshots, HMAC-signed node→hub ingest.
* Numbers (README): audio P 0.966 / R 0.768 / FPR 2.5 % / AUC 0.949 (held-out recordings); vision P 0.939 / R 0.921 / mAP50 0.951 (203 val imgs, 74 ms/frame on laptop); fusion 0 false DRONE alarms in a replayed quiet hour vs 100/36/8 per single sensor; localization median 0.8–1.2 m calibrated / 2–2.7 m mis-calibrated (simulated).

## Exact next commands once hardware is connected
```bash
cp .env.example .env     # set PI_HOST (Pi hotspot IP first), PI_USER, UNOQ_HOST, HUB_URL=http://<pi ip>:8000, NEST_NAME if renamed
./deploy/pi.sh           # Node A: I2C, deps, Piper, i2cdetect report, Nest discovery, systemd; prints dashboard URL

# then open the dashboard, press "Test · Wi-Fi RF" -> LCD red, matrix flashes, Nest speaks

```
